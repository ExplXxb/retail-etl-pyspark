# Retail ETL на PySpark

ETL-конвеєр для обробки даних про продажі інтернет-магазину на Apache Spark (PySpark).
Лабораторна робота № 4 з дисципліни «Методи та засоби інженерії даних та знань».

Набір даних: [Online Retail II](https://doi.org/10.24432/C5CG6D) (UCI Machine Learning Repository) –
1 067 371 рядок чеків британського інтернет-магазину за 01.12.2009–09.12.2011.

## Структура конвеєра

| Шар | Що містить | Як отримано |
|---|---|---|
| Bronze | сирі рядки чеків з двох CSV-файлів | читання за явною схемою, `unionByName` |
| Silver | очищені продажі (996 057 рядків) | видалення дублікатів, службових кодів і скасованих продажів |
| Gold | виміри `dim_product` і `dim_customer` | агрегування Silver, одна назва на товарний код |

Шари Silver і Gold записуються у Parquet, результати завдань – у CSV.

## Завдання

| № | Завдання | Техніка |
|---|---|---|
| 1 | Товари, які купували клієнти з Німеччини | фільтр, `join` |
| 2 | Клієнти з першою покупкою в грудні 2009 р. | фільтр за діапазоном дат |
| 3 | Товари з медіанною ціною понад 20 £ | `percentile_approx`, `join` |
| 4 | Оптові покупки (≥ 100 шт.) з даними клієнта й товару | `join` трьох таблиць |
| 5 | Скасування за країнами | Spark SQL |
| 6 | Топ-50 чеків за кількістю позицій | віконні функції |
| 7 | Топ-10 товарів за кожен квартал | `row_number()` у вікні |
| 8 | Топ-10 товарів у кожній країні | `row_number()` у вікні |

## Запуск

1. Завантажити файли `online_retail_2009-2010.csv` і `online_retail_2010-2011.csv` на Google Drive
   у папку `MyDrive/retail-data/`.
2. Відкрити `retail_etl.ipynb` у Google Colab і виконати всі комірки (Runtime → Run all).
3. Результати завдань і графіки з'являться в `MyDrive/retail-data/retail-results/`,
   шари сховища – в `MyDrive/retail-data/lakehouse/`.

Локально ноутбук читає дані з папки `data/` (не зберігається в репозиторії).
